## Summary

Build a small, clean educational tokenizer web application that allows users to enter text
or upload TXT/PDF files and visualize how that text is split into tokens by two independent
tokenizers: Tiktoken (using real OpenAI encodings) and a Custom Tokenizer (regex-based,
with in-memory vocabulary management). The frontend is React + TypeScript with a
neon-gradient cyberpunk dark-mode aesthetic. The backend is FastAPI + Python with Pydantic
schemas, PyMuPDF for PDF extraction, and pytest for testing. No database, no auth, no
persistent storage.

localhost in dev; Tiktoken vocabulary unmodified

**Scale/Scope**: Single-user local dev tool; 2 API routes + 1 utility route + 1 reset route;
~8 React components; ~4 backend services

## Architecture & Component Design

### System Architecture

```
Browser (React SPA)
  |
  | HTTP (multipart/form-data)
  |
FastAPI (uvicorn)
  ├── GET  /health
  ├── GET  /tokenize/encodings
  ├── POST /tokenize/text       → validates → service → statistics → response
  ├── POST /tokenize/file       → validates → file_processor → service → statistics → response
  └── POST /tokenize/custom/reset → custom_tokenizer_service.reset()
           |
           ├── TiktokenService           (stateless, wraps tiktoken library)
           ├── CustomTokenizerService    (stateful, owns in-memory VocabularyState)
           ├── FileProcessor             (stateless, validates + extracts text)
           └── StatisticsCalculator      (pure functions, no state)
```

### Backend Service Design

#### TiktokenService

- **State**: Stateless. Caches `tiktoken.Encoding` objects per encoding name in a module-level dict to avoid repeated BPE model loads.
- **Key method**: `tokenize(text: str, encoding: str) -> list[TokenSchema]`
  - Validates encoding against `SUPPORTED_ENCODINGS` constant; raises `ValueError` if invalid.
  - Calls `enc.encode(text)` to get token IDs.
  - Decodes each ID via `enc.decode_single_token_bytes(id)`, converting bytes to string (UTF-8, with hex fallback).
  - Returns list of `TokenSchema` with index, token_id, token_text.
- **Constraint**: MUST NOT modify or filter Tiktoken output in any way.

#### CustomTokenizerService

- **State**: Stateful. Holds `VocabularyState` (dict + next_id counter).
- **Regex pattern** (compiled once at module level):
  ```
  r"'s|'t|'re|'ve|'m|'ll|'d|\s*[a-zA-Z]+|\d+|[^\s\w]"
  ```
- **Key method**: `tokenize(text: str) -> tuple[list[TokenSchema], list[VocabularyEntrySchema], list[int]]`
  - Split text with `re.findall(PATTERN, text)` → raw token strings.
  - For each token string: look up in `self._vocab` dict.
    - If found: increment frequency, `is_new=False`.
    - If not found: assign `self._next_id`, create entry, increment counter, `is_new=True`.
  - Return (token list, full vocabulary snapshot, new_token_ids list).
- **Key method**: `reset() -> None`
  - Clears `self._vocab = {}`, sets `self._next_id = 0`.
- **Key method**: `get_vocabulary() -> list[VocabularyEntrySchema]`
  - Returns snapshot of current vocabulary sorted by `token_id`.
- **Singleton**: Instantiated once at app startup via FastAPI dependency injection (`Depends`).

#### FileProcessor

- **State**: Stateless.
- **Key method**: `extract_text(file_bytes: bytes, filename: str, content_type: str) -> tuple[str, SourceType]`
  - Check extension and content_type → reject if not .txt or .pdf.
  - Check `len(file_bytes) > MAX_UPLOAD_BYTES` → raise 413.
  - For TXT: decode bytes as UTF-8 (with `errors="replace"`), strip, check empty.
  - For PDF: `fitz.open(stream=file_bytes, filetype="pdf")` in try/except fitz.FileDataError.
    - Concatenate `page.get_text("text")` for all pages.
    - Strip; check empty → raise 400 "no extractable text".
  - Returns `(extracted_text, source_type)`.

#### StatisticsCalculator

- **State**: Stateless — pure functions only.
- `char_count(text: str) -> int` — `len(text)`
- `word_count(text: str) -> int` — `len(text.split())`
- `tokens_per_word(token_count: int, word_count: int) -> float` — safe divide, 4dp
- `tokens_per_char(token_count: int, char_count: int) -> float` — safe divide, 4dp

#### Route Design (tokenize.py)

All routes are thin controllers:
1. Accept `UploadFile` / `Form` fields.
2. Call `FileProcessor.extract_text()` (file routes only).
3. Call `TiktokenService.tokenize()` or `CustomTokenizerService.tokenize()`.
4. Call `StatisticsCalculator.*` functions.
5. Assemble `TokenizationResultSchema` and return.

No business logic in route functions. Error handling via FastAPI `HTTPException`.

### Frontend Component Design

#### App.tsx — State Orchestration

Owns all top-level state:

| State | Type | Notes |
|-------|------|-------|
| `inputMode` | `'text' \| 'txt' \| 'pdf'` | Controls which input is shown |
| `textInput` | `string` | Direct text entry |
| `uploadedFile` | `File \| null` | Uploaded file |
| `tokenizerMode` | `TokenizerMode` | `'tiktoken'` or `'custom'` |
| `selectedEncoding` | `string` | Selected Tiktoken encoding |
| `availableEncodings` | `string[]` | Fetched from `/tokenize/encodings` on mount |
| `result` | `TokenizationResult \| null` | Last successful response |
| `isLoading` | `boolean` | Request in flight |
| `error` | `string \| null` | Error message to display |

Handlers: `handleTokenize()`, `handleReset()`. Pass down as props.

#### Component Responsibilities

| Component | Responsibility |
|-----------|---------------|
| `InputPanel` | Mode tabs (Text/TXT/PDF), textarea, file input. Emits text or File. |
| `TokenizerControls` | Tokenizer mode toggle (Tiktoken/Custom). Encoding `<select>` (shown only when Tiktoken). |
| `TokenizeButton` | Renders disabled + spinner when `isLoading`. |
| `ExtractedTextPanel` | Shows `result.original_text` when `source_type` is `txt` or `pdf`. Collapsible. |
| `StatisticsPanel` | Five stat cards: char count, word count, token count, tokens/word, tokens/char. |
| `TokenTable` | Scrollable table. Columns: Index, Token ID, Token Text. Rows = `result.tokens`. |
| `VocabularyPanel` | Shown only in Custom mode. Table: ID, Token, Frequency, Status badge. Reset button. |
| `ErrorMessage` | Red neon dismissible alert. Displays `error` string. |

#### API Service (services/api.ts)

- `fetchEncodings(): Promise<string[]>` — GET /tokenize/encodings
- `tokenizeText(params): Promise<TokenizationResult>` — POST /tokenize/text
- `tokenizeFile(params): Promise<TokenizationResult>` — POST /tokenize/file
- `resetVocabulary(): Promise<void>` — POST /tokenize/custom/reset
- All functions throw `ApiError` (with `.detail` string) on non-2xx responses.
- No axios. Native `fetch` only.
